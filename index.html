What you actually do

Hold the line around a single core. Spend scrap on defenses, read the incoming wave, and choose one run-only upgrade each time you clear it.

Build the line

Walls, generators, turrets, sniper turrets, Tesla coils and mortars — each with upgrade and refund handling.

Read the threat

Standard, runner, tank, healer, shooter, bomber, shielded and flying enemies, plus rotating boss archetypes.

Draft your run

After every cleared wave, pick one of three roguelite upgrades that last only for that run.

Rewind time

One free rewind per run. Further rewinds cost a persistent boss core from your meta-progression.

Grow forever

A tech tree, enemy codex, achievements, run history and local records persist between runs.

Feel it land

Procedural chiptune, spatialized effects, CRT overlays, pixel font and hit feedback.

Ways to play

Five modes, three maps and selectable mutators — plus a fully remappable control scheme.

Normal — classic wave defense Daily Seed — same run for everyone Endless — no finish line Rhythm — beat-driven bonus Local co-op — two players, one screen Maps: Arena · Cross · Maze

Before you judge it

This is an enhanced development build. Core systems are implemented and covered by static and simulated-runtime regression checks, but not every mode, input method, device and interaction has completed hands-on browser QA. The screenshots above are captured from the current build in a headless browser rather than from a live interactive session. See the repository's testing notes for the outstanding manual checklist.
