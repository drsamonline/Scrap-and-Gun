# Controls

## Player 1

| Action | Default input |
| --- | --- |
| Move | `W A S D` or arrow keys |
| Aim | Mouse pointer |
| Fire / place selected building | Left mouse button |
| Select building slots 1–6 | Number keys `1`–`6` |
| Upgrade building | `Shift` + click |
| Preview refund / sell | Right-click / hold right-click |
| Cycle weapon | `Q` / `E` or mouse wheel |
| Dash | `Shift` |
| Bomb | `F` |
| Advance wave | Hold `Space` for 0.5 seconds |
| Pause | `Esc` |
| Mute | `M` |
| Fullscreen | `F11` |

## Modes and secondary input

- On the title screen, press `R` to select Rhythm mode.
- On the title screen, press `C` to toggle local co-op.
- Player 2: `I/J/K/L` to move, Numpad `0` to fire, Numpad `1` to dash.

## Touch

| Action | Input |
| --- | --- |
| Move | Drag anywhere on the left half of the field |
| Aim and fire | Drag anywhere on the right half of the field (aim is relative to where you touch) |
| Dash / Bomb | `DASH` / `BOMB` buttons at the bottom right |
| Select a building | Tap a slot in the bottom build bar |
| Place the selected building | Tap a tile on the field; tap the slot again to cancel |
| Skip the build phase | `NEXT >` button in the bottom bar |
| Pause | Button at the top left of the HUD |

Rotate the device to landscape to play. In portrait a rotate prompt appears with a "Continue in portrait" option. Touch menus (title, pause, settings, draft, time-loop) respond to taps.
- Standard browser gamepad mapping: left stick move, right stick aim, RT fire, A dash, B bomb, LB/RB weapon cycling. Mapping may differ by browser and controller.

Most supported key bindings can be changed in Settings.
