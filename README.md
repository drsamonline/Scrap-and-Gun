## Quick start

This is a browser-based HTML5 Canvas game. The full game package is still being transferred into this repository; do not treat this initial README-only commit as a playable release.

## Planned package contents

- `index.html`, `styles.css`
- `game.js` and production `game.min.js`
- PWA manifest, service worker and app icon
- Tests, architecture notes, controls, and release audit
- PolyForm Noncommercial License 1.0.0

## QA status

This project is an enhanced development build. Automated syntax, static and simulated-runtime checks are not equivalent to hands-on browser QA. A release should not be advertised as fully validated until manual testing is complete.
